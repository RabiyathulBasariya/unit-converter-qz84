# Metric/Imperial Unit Converter

A simple unit converter built with **HTML**, **CSS**, and **JavaScript**, converting a single input across length, volume, and mass simultaneously.

## Preview

Enter a number once, click Convert, and instantly see it converted both ways — metric to imperial and imperial to metric — across three categories at the same time.

## Features

- Converts Length (meters ↔ feet), Volume (liters ↔ gallons), and Mass (kilograms ↔ pounds) from one shared input
- Shows both conversion directions at once for each unit type
- Input validation — displays a message if the field is empty or zero
- Runs automatically on page load so results aren't blank before interacting
- Clean purple-and-white themed layout with custom Google Font (`Inter`)

## Tech Stack

- HTML5
- CSS3 (custom input styling, hidden number-spinner arrows, card-style result sections)
- JavaScript (template literals, DOM manipulation, event listeners, input validation)
